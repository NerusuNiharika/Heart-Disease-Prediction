# ❤️ Heart Disease Prediction System

A Machine Learning based web application that predicts the risk of heart disease using Logistic Regression and the Framingham dataset.

---

# 🚀 Features

- Heart Disease Risk Prediction
- Logistic Regression Model
- Probability Prediction
- Dark Modern UI
- Streamlit Web App
- Interactive Inputs

---

# 🧠 Machine Learning Workflow

- Data Cleaning
- Feature Selection
- Standard Scaling
- Logistic Regression Training
- Model Evaluation
- Prediction System

---

# 📊 Technologies Used

- Python
- Streamlit
- Scikit-learn
- Pandas
- NumPy

---

# 📁 Project Structure

```text
Heart-Disease-Prediction/
│
├── app.py
├── framingham.csv
├── heart_model.pkl
├── scaler.pkl
├── requirements.txt
├── README.md
```

---

# ▶️ Run Locally

Install dependencies:

```bash
pip install -r requirements.txt
```

Run Streamlit app:

```bash
streamlit run app.py
```
